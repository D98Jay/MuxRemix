# MuxRemix
Not a fancy theme, just a clean design of muOS standard layout with custom color palettes, font and good spacing. Based on OneTwo by bulkh.

### What this does
- [x] Clean aesthetics, stunning color palettes
- [x] Fast theme switching between alternatives
- [x] Support all device resolutions (include TUI-SP & TUI-Brick)
- [x] Optimal font size for each resolutions
- [x] Not language depend

### Icons and Console images
I use icons and images from [OneTwo](https://github.com/bulkh/OneTwo) theme, as this theme is based on. Big shout out to bulkh!

### Theme Alternatives
Color schemes are based on default MustardOS theme, with a different style. Scheme files is structured in very customizable way for new theme addition later on.
